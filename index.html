Install the whole team

Copies every agent into your user-level agents folder, so they're available in every Claude Code project. To install just one, open it and use its install command.

mkdir -p ~/.claude/agents && cd ~/.claude/agents && for a in sales-proposal-strategist engineering-software-architect engineering-platform-engineer design-ui-designer design-ux-architect design-ux-researcher design-ui-finish-gate-reviewer design-persona-walkthrough design-brand-guardian design-visual-storyteller design-image-prompt-engineer design-inclusive-visuals-specialist design-whimsy-injector; do curl -fsSLO https://meik-cm.github.io/claude-agents/.claude/agents/$a.md; done
